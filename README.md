## 📸 PhotoBid

<p align="center">
  <strong>Share it. Bid it. Own the spotlight.</strong>
</p>

PhotoBid is a social platform where **photos compete for attention**.

Users can publish photos, discover content, interact with creators, and bid to give posts more visibility.

### ✨ Highlights

* 🖼️ Social image discovery
* 💰 Paid bidding system
* 🏆 Rankings & Hall of Fame
* 👤 Creator profiles
* 🔐 Authentication & Google Sign-In
* 🛡️ Content moderation & reporting
* ☁️ Cloudflare R2 image infrastructure
* 💳 Payment processing & webhook lifecycle
* 📱 Responsive mobile-first experience
* 🔎 SEO & search engine optimization

### 🛠️ Built With

`Next.js` `TypeScript` `MongoDB Atlas` `Cloudflare R2` `Dodo Payments` `Vercel`

> 🚀 Built and launched independently.

## 🧠 Synapse

### Semantic Yield Neural Adaptive Processing & Storage Engine

Synapse is AI memory infrastructure designed to give applications **persistent contextual memory** across conversations and LLM sessions.

Instead of treating every conversation as isolated, Synapse focuses on storing, retrieving, and organizing meaningful context.

### ✨ Focus Areas

* 🧠 Persistent AI memory
* 🔎 Semantic retrieval
* 🗃️ Vector databases
* 🤖 LLM context management
* ⚡ High-performance APIs
* 📦 Developer SDKs
* 🔄 Context-aware applications

### 🛠️ Built With

`Python` `FastAPI` `Qdrant` `Redis` `MongoDB` `Next.js`

---

## 💬 Masher

### Real-Time Messaging Platform

Masher is a cross-platform messaging application focused on **real-time communication, performance, and scalable backend architecture**.

Built while exploring real-world challenges around WebSockets, distributed systems, caching, synchronization, and offline-first mobile applications.

### ✨ Highlights

* 💬 Real-time messaging
* ⚡ Socket-based communication
* 🔴 Redis-backed infrastructure
* 📱 React Native mobile application
* 🗃️ MongoDB backend
* 🔄 Offline-first local storage
* 🔔 Real-time events
* 🚀 Scalable server architecture

### 🛠️ Built With

`React Native` `Node.js` `Socket.IO` `Redis` `MongoDB` `WatermelonDB`

---

## 📦 Synapse SDK

A lightweight, **zero-dependency TypeScript SDK** for integrating Synapse into Node.js and browser applications.

### ✨ Goals

* 🪶 Minimal dependencies
* ⚡ Simple developer experience
* 🔌 Easy AI memory integration
* 📦 TypeScript-first
* 🌐 Browser & Node.js compatible

Published as an npm package under **Khare Industries**.

`TypeScript` `npm` `AI` `SDK`
